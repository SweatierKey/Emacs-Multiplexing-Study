# tmux-el

Categoria: **controller**. [Sorgente upstream](https://github.com/abougouffa/tmux.el). Revisione: `26b2673eb5a15150f8f05b109aca77b33db22b53`.

## Funzionamento

Wrapper Lisp del CLI tmux per comandi, invio testo, directory e selezione.

## Utilizzo umano e limiti

Feature tmux. Il renderer resta tmux/terminale esterno; non è un nuovo emulatore in-buffer.
