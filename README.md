# Emacs Multiplexing Study

Studio riproducibile di terminal emulator e terminal multiplexer per Emacs.

Lo studio distingue sempre ricerca, revisione del codice, test realmente eseguiti e limitazioni ambientali. La configurazione di test abilita Vertico e Marginalia senza sostituire le keymap native dei progetti. Le sessioni remote del laboratorio sono esclusivamente locali e non contattano server aziendali.

I risultati, il report e le registrazioni vengono aggiunti durante la costruzione verificata di questo repository.
